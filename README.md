## Installation

Goto where you want a copy and use:

```bash
git clone https://github.com/CoolBurger50/ProjectSaturn
```

Make sure to change the file pathing in
```bash
/ProjectSaturn/Main/src/HelperMethods.java
```
and 
```bash
/ProjectSaturn/Main/MasterRunner.sh
```
Then simply run the MasterRunner.sh script
